# Changelog

## 0.1.0 — Unreleased

- Added the first replayable incident and deterministic plumbing baseline.
- Added typed tools, BM25 retrieval, evidence ledger, API, CLI, and metrics.
- Added evaluation, dataset generation, LoRA training, and load-test entry points.
- Added container, Kubernetes, CI, security, architecture, and contribution documentation.

## 0.2.0 — 2026-08-14

- Replaced the scripted path with a bounded model-driven observe–act loop.
- Added persistent ingestion and SQLite FTS5 retrieval with provenance.
- Expanded the benchmark to five incident classes with distractors and grading oracles.
- Added live-model, retrieval, citation, and agent-planning evaluations.
- Added a Qwen3-1.7B llama.cpp development runtime and published measured results.
- Added frontend knowledge ingestion and a live benchmark scorecard.
